Type: Unified System Architecture
---
**Components:**
* **Environmental Sensors:** Monitors Salinity/Temp.
* **LSTM Predictor:** Core forecasting engine (MAE: 0.008 PSU).
* **DRL Controller:** Decision-making agent for phase shifts.
* **NSGA-II Optimizer:** Multi-objective refinement unit.
* **ISAC Base Station:** Source of communications and radar signals.
* **RIS Array:** Reconfigurable surface for beam steering.
* **Legitimate Users:** Target receivers providing channel feedback.
* **Eavesdroppers:** Adversarial targets for signal nullification.

**Operational Flow:**
1. Sensors feed real-time oceanographic data to the LSTM Predictor.
2. LSTM provides short-term parameter forecasts to the DRL Controller.
3. DRL agent evaluates states and interacts with the NSGA-II Optimizer via a Reward Function.
4. Optimized phase shifts are applied to the RIS Array.
5. RIS enhances signals toward Legitimate Users and nullifies links toward Eavesdroppers.

**System Metrics:**
* **BER Reduction:** 41.4%
* **Secrecy Rate:** 8.2 bps/Hz
* **Reconfig Latency:** 37.5 μs
* **Energy Savings:** 22.2%
