**Components:**
- **Electronic Rx:** Antenna -> Mixer (x) -> DSP. LO (Local Oscillator) -> Multiplier (xN) -> Mixer.
- **Photonic Rx:** Antenna -> Modulator (Mod) -> PD (Photodiode) -> DSP. Laser -> Modulator.
- **Mixed Rx:** Antenna -> Mixer -> Modulator -> PD -> DSP. Electronic LO path (LO -> Multiplier -> Mixer). Photonic LO path (Laser -> Modulator).

**Flow:**
The diagram contrasts three receiver architectures for ISAC/sensing:
1.  **Electronic Rx:** Purely electronic mixing of the received signal with a multiplied Local Oscillator (LO) followed by DSP.
2.  **Photonic Rx:** The received electrical signal drives an optical modulator. A laser source provides the optical carrier. The modulated signal is detected by a photodiode and processed by DSP.
3.  **Mixed Rx:** A hybrid approach where the received signal is first down-converted electronically (Mixer + Electronic LO) and then modulated onto an optical carrier (Modulator + Laser) before photodetection and DSP. This combines electronic down-conversion with photonic processing.

Type: System Diagram / Schematic (Flowchart/DSP Block)
---
**Components:**
- **Tx DSP:**
    -   **Sensing Path:** LFM Signal (Linear Frequency Modulation) -> Up Convert -> FIR Filtering -> Power Allocation.
    -   **Communication Path:** Data in -> Mapping -> Up Sampling -> Up Convert -> Power Allocation.
    -   **Combining:** FDM Combining -> AWG (Arbitrary Waveform Generator).

**Flow:**
Flowchart of the DSP Logic for the Transmitter.
1.  **Signal Generation:** Separate paths for Sensing (LFM radar signal) and Communication (Data stream).
2.  **Processing:** Both signals are up-scaled/converted. The LFM signal is specifically FIR filtered (likely to shape spectrum).
3.  **Aggregation:** The signals are combined using Frequency Division Multiplexing (FDM) after power allocation, and sent to the AWG for physical generation.

Image: _page_7_Figure_5.jpeg
Type: System Diagram / Schematic (Flowchart/DSP Block)
---
**Components:**
- **Rx DSP:** Resample -> Synchronization -> FDM Filtering -> Volterra Equal. (Equalization) -> Down Convert -> Down-sampling -> Equal. -> QAM DeMod. -> BER Calculation.

**Flow:**
Flowchart of the DSP Logic for the Receiver (Communication path).
1.  **Pre-processing:** Resampling and Synchronization to align the received signal.
2.  **Separation:** FDM Filtering separates the communication signal from the sensing signal.
3.  **Correction:** Volterra Equalization (likely for nonlinear compensation) and linear Equalization compensate for channel impairments.
4.  **Demodulation:** Down conversion, down-sampling, and QAM demodulation recover the bits.
5.  **Metrics:** BER determines performance.
