Image: _page_12_Figure_2.jpeg
Type: Flowchart (Optimization Algorithm)
---
**Process:** 
1. Start ($j=1, \eta_i = \eta_{min}$).
2. Set ratios.
3. Deduce location via (8)-(11).
4. Calculate RMS error.
5. Loop until $j=N_x N_y$.
6. Calculate CDF.
7. Check if $\delta_{90} < \delta_{opt}$.
8. Increment $\eta_i$.
9. End when $\eta_i = \eta_{max}$.
