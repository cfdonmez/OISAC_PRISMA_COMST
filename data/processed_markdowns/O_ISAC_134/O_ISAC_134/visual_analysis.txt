Image: _page_2_Picture_1.jpeg
Type: System Diagram / Schematic (Quantum-Enhanced ISAC Transceiver)
---
Components:
- Pump Laser: 1064 nm, 10 W CW.
- PPLN Crystal: Periodically poled LiNbO3 for SPDC.
- Signal Photon Source: 1550 nm idler.
- Idler Photon Source: 1535 nm (retained locally).
- IQ Modulator: Classical data overlay.
- EDFA: Signal amplification.
- Circulator: Tx/Rx port separation.
- Target Scene.
- SNSPD: Superconducting nanowire single-photon detector.
- Coincidence Counter: Entanglement verification.
- Classical Receiver: Homodyne detection.
- DSP: Joint quantum-classical processing.

Flow:
1. Pump → PPLN → Entangled pairs (signal + idler).
2. Idler → Local SNSPD (retained for coincidence).
3. Signal → IQ Mod → EDFA → Circulator → Target.
4. Return → Circulator → SNSPD / Classical Rx.
5. Coincidence Counter + DSP → Range/Data extraction.
