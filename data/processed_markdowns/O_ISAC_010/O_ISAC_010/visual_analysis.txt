Image [_page_2_Figure_5.jpeg]: Diagram: This image is a block diagram illustrating the Digital Signal Processing (DSP) steps involved in both the Transmitter (Tx-DSP) and Receiver (Rx-DSP) sides of a communication system.
*   **Tx-DSP (Transmitter Digital Signal Processing) flow (left to right):**
    1.  **QAM Mapping:** Converts data bits into Quadrature Amplitude Modulation (QAM) symbols.
    2.  **DMT Modulation:** Performs Discrete MultiTone modulation, typically using Inverse Fast Fourier Transform (IFFT) to create orthogonal subcarriers.
    3.  **CP adding:** Adds a Cyclic Prefix to each DMT symbol to mitigate inter-symbol interference.
    4.  **RRC filtering:** Applies Root Raised Cosine filtering for pulse shaping and bandwidth efficiency.
    5.  **Resampling:** Adjusts the sampling rate of the signal.
*   **Rx-DSP (Receiver Digital Signal Processing) flow (right to left):**
    1.  **Resampling:** Adjusts the sampling rate of the received signal.
    2.  **Matched filtering:** Applies a filter matched to the transmitted pulse shape to maximize SNR.
    3.  **Synchronization:** Aligns the received signal in time and frequency.
    4.  **Equalization:** Compensates for channel impairments like dispersion and fading.
    5.  **DMT Demodulation:** Performs Discrete MultiTone demodulation, typically using Fast Fourier Transform (FFT) to recover subcarrier data.
    6.  **BER/SNR Calculation:** Calculates the Bit Error Rate and Signal-to-Noise Ratio to evaluate system performance.
This diagram provides a high-level overview of the signal processing chain for a DMT-based optical communication system.
