Type: System Diagram / Schematic (Photonic Integrated ISAC Transceiver)
---
Components:
- Laser Array: 4-channel DFB at 1550±2 nm.
- MMI (Multi-Mode Interference): 4×1 combiner.
- IQ Modulator Array: 4 integrated I/Q modulators.
- AWG (Arrayed Waveguide Grating): Wavelength routing.
- SOA (Semiconductor Optical Amplifier): On-chip gain.
- Edge Coupler: Fiber-to-chip interface.
- PIC Die: 3.5 mm × 8 mm InP photonic chip.
- Driver IC: 4-channel RF driver.
- TIA Array: 4-channel transimpedance amplifiers.

Flow:
1. Laser Array → MMI combiner → IQ Modulator Array (OFDM waveform).
2. AWG routes wavelengths → SOA amplifies.
3. Edge Coupler interfaces to fiber.
4. Receive path: Edge Coupler → AWG → PD Array → TIA Array.
