Type: System Diagram / Schematic (Coherent FSO-ISAC Architecture)
---
Components:
- CW Laser: 1550 nm, <100 kHz linewidth.
- IQ Modulator: Dual-parallel MZM.
- EDFA: 20 dBm output.
- Telescope: 50 mm aperture.
- Target Scene.
- Rx Telescope.
- 90° Hybrid: Coherent mixing.
- Balanced PDs ×4.
- ADC: 100 GSa/s.
- DSP: MIMO processing.
- LO: Local oscillator tap.

Flow:
1. Laser → IQ Mod → EDFA → Tx Telescope → Free-space.
2. Return signal → Rx Telescope → 90° Hybrid with LO.
3. Balanced PDs → ADC → DSP → Range/Data output.
