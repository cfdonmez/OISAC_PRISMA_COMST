## Image: _page_1_Figure_10.jpeg
### Type: Multi-Panel Conceptual Diagram (Quasi-TTD Beamformer Principle)

### Panel (a) - Frequency-Comb-Steered Beamformer:
- Dual optical frequency combs (Signal + LO)
- Heterodyne mixing scheme
- Linear frequency increments Δf across antennas
- Continuous beam steering via Δf and Δφ adjustment

### Panel (b) - Linear Antenna Array Principle:
- N-element array with spacing d
- Beam direction θ_B
- Phase front perpendicular to beam direction
- Time delay τ_B = d·sin(θ_B)/c

### Panel (c) - Conventional Phase-Shifter Array (Problem):
- Different frequencies → different beam directions
- Beam squint issue at wideband operation
- LFM signal dispersed in space

### Panel (d) - Proposed Quasi-TTD Beamformer (Solution):
- All frequencies aligned to same beam direction
- Squint-free beamforming
- Linear frequency offset compensates delay

### Key Equations:
- Δf = κ·τ_B (frequency increment)
- Δφ = 2π·f₀·τ_B (phase increment)
- θ_B = arcsin(Δf·c / κ·d) (beam direction)

### O-ISAC Relevance:
- Core innovation: delay-line-free TTD for ISAC
- Solves beam squint for wideband ISAC
