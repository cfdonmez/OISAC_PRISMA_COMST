Type: System Diagram / Schematic (Photonic ISAC for Automotive LiDAR-Communication)
---
Components:
- Tunable Laser: 1550 nm, 100 kHz linewidth, C-band tuning.
- MZDI (Mach-Zehnder Delay Interferometer): Frequency-to-amplitude conversion.
- IQ Modulator: Dual-parallel MZM, 25 GHz bandwidth.
- EDFA: Booster amplifier, 23 dBm output.
- Circulator: Tx/Rx isolation.
- Beam Scanner: 2D MEMS mirror, 30° × 10° FOV.
- Telescope: 50 mm aperture, 0.1° divergence.
- Target Vehicle: Multiple retroreflectors.
- Balanced Receiver: Coherent detection.
- ADC: 40 GSa/s digitizer.
- FPGA: Real-time processing.
- V2X Interface: 802.11p/C-V2X modem.

Flow:
1. Tunable Laser → MZDI (frequency chirp) → IQ Mod (data overlay).
2. EDFA → Circulator → Beam Scanner → Telescope → Free space.
3. Return from Target Vehicle → Telescope → Beam Scanner → Circulator.
4. Balanced Receiver → ADC → FPGA → V2X Interface.
---
