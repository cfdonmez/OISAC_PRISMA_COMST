IMAGE: _page_4_Figure_2.jpeg
TYPE: Neural Network Architecture
DESCRIPTION: Detailed structure of the SDOA-Net for DOA estimation.
COMPONENTS:
- Input: Received signals M_B x 2N (Real and Imaginary parts).
- Input Layer (FC): 2N x M_f*M_r.
- FC Output: M_B x M_f*M_r.
- Convolution Layers: Two blocks showing 1D convolution (M_f filters), Reshape, and Batch normalization + ReLU.
- Output Layer (FC): Reshaped complex vector mapped to Real and Imaginary parts.

IMAGE: _page_5_Figure_2.jpeg
TYPE: Processing Flow / Complex Vector Mapping
DESCRIPTION: Visualization of how SDOA-Net output g(m) is processed into a spatial spectrum.
STEPS:
1. g(m) split into Real part g_{0:N-1}(m) and Imaginary part g_{N:2N-1}(m).
2. Combined into Complex vector: g_{0:N-1}(m) + j*g_{N:2N-1}(m).
3. Complex vector multiplied by Steering vector a(zeta).
4. Output: Spatial spectrum (Amplitude vs Spatial angle).
================================================================================
IMAGE: _page_6_Figure_2.jpeg
TYPE: Flowchart
DESCRIPTION: 7-step training procedure for SDOA-Net to handle imperfect arrays.
STEPS:
1. Start.
2. Perfect array using all the data.
3. Position perturbations using all the data.
4. Inconsistent gains using all the data.
5. Inconsistent phases using all the data.
6. Mutual coupling effect using all the data.
7. Nonlinear effect using all the data.
8. All the imperfect effect using all the data.
9. Condition: Is training completed? (No -> Loop back to step 2; Yes -> End).
