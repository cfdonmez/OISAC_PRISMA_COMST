Type: System Diagram / Schematic (Silicon Photonic ISAC Transceiver)
---
Components:
- Laser Source: External, 1550 nm, <100 kHz linewidth.
- Grating Coupler: Fiber-to-chip interface.
- MZM Array: 4× Mach-Zehnder modulators.
- MMI Coupler: 1×4 splitter.
- Thermo-optic Phase Shifter: Beamforming.
- Ge PD Array: 4× germanium photodetectors.
- OPA (Optical Phased Array): 16 elements.
- Edge Coupler: High-power output.

Die Specifications:
- Die size: 4.2 × 5.8 mm.
- Technology: 220 nm SOI.
- Power: 250 mW total.

Flow:
1. Laser → Grating Coupler → MMI Splitter → 4× MZM.
2. MZM outputs → Phase Shifters → Combiner → OPA.
3. Return: OPA → Ge PD Array → TIA (off-chip).
