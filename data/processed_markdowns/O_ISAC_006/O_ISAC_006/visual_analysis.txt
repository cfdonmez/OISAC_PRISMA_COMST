Image [_page_1_Picture_4.jpeg]: Diagram: This image displays two block diagrams (a and b) illustrating different anomaly detection algorithms based on polarimeter input.
a) SOPAS Anomaly Detector: This diagram shows the signal flow for the SOPAS (State of Polarization Anomaly Score) detector. The input signal S[n] from a "Polarimeter" is fed into a block that computes the cosine similarity between S[n] and S[n-1], effectively measuring the change in SOP. The arccos() function is applied, and the result is multiplied by a factor (f_t). This signal then passes through a Smoothing Low-Pass Filter (LPF) with frequency response H(f) and finally into a Threshold Detector, which outputs a binary anomaly decision d[n] based on whether the input exceeds a predefined threshold.
b) SOP-PSDG Anomaly Detector: This diagram illustrates a more complex anomaly detection scheme. The polarimeter output S[n] is separated into its S1, S2, and S3 components. Each component undergoes a Fast Fourier Transform (FFT) and then a High-Pass Filter (HPF) to obtain P_k^I[n] and P_k^Q[n] (representing power spectral density components). These filtered components are used in an "Update PSD statistics" block which computes the mean (µ) and variance (σ²) of P_k^I[n] and P_k^Q[n] via a control update loop. The deviation |P_k^I[n] - µ_k^I(n)| and |P_k^Q[n] - µ_k^Q(n)| is then computed. This combined metric is then fed through a Smoothing LPF and a Threshold Detector, similar to the SOPAS detector, to produce the anomaly output d[n].
