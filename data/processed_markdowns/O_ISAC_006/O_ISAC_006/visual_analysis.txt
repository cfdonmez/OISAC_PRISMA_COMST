TYPE: Flowchart / DSP Scheme
DESCRIPTION: Two DSP schemes for anomaly detection in SOP extraction.
COMPONENTS:
- Scheme (a): SOPAS Anomaly Detector. 
  - Input: Polarimeter S[n].
  - Process: Cosine Similarity -> arccos(.) -> Smoothing LPF -> Threshold Detector.
  - Output: d[n].
- Scheme (b): SOP-PSDG Anomaly Detector.
  - Input: Polarimeter S[n].
  - Process: PSD computation (FFT, square, HPF) for S1[n], S2[n], S3[n] -> Summation -> Update PSD statistics -> Normalization -> Smoothing LPF -> Threshold Detector.
  - Output: d[n].
