Type: System Diagram / Schematic (Photonic Beamforming ISAC)
---
Components:
- ECL: External Cavity Laser, 1550 nm, <100 kHz linewidth.
- 1×N Splitter: 1 to 16 optical power divider.
- OBFN (Optical Beamforming Network): 16-element true-time delay.
- TTD Elements ×16: Silicon photonic delay lines (0-100 ps range).
- MZM Array ×16: LiNbO3 modulators for OFDM encoding.
- EDFA Array ×16: Per-channel amplification (20 dBm each).
- Antenna Array: 16-element phased array, λ/2 spacing.
- LNA Array ×16: Low-noise front-end.
- PD Array ×16: High-speed photodetectors (40 GHz).
- Combiner: RF signal summation.
- ADC: 80 GSa/s digitizer.
- DSP: Beamforming and ISAC processing.

Flow:
1. ECL → 1×N Splitter → 16 parallel paths.
2. Each path: TTD → MZM → EDFA → Antenna element.
3. Free-space propagation to/from targets.
4. Return: Antenna → LNA → PD → Combiner → ADC → DSP.
