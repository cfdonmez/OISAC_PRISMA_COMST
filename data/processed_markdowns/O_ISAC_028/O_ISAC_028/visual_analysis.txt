Type: System Diagram / Schematic (VLC-based Indoor Positioning System)
---
Components:
- LED Transmitters (LED1, LED2, LED3, LED4): Located at known ceiling positions for trilateration.
- Photodetector (PD): Receives optical signals from LEDs.
- Mobile Device / User Terminal: Contains PD and processing unit.
- Ceiling Grid: Reference coordinate system for LED placement.
- Floor Plane: User movement area with target positioning zones.

Flow:
1. LED1-LED4 transmit unique identification signals (e.g., different frequencies or codes).
2. PD on the mobile device receives combined optical signals.
3. Signal processing separates each LED's contribution via filtering.
4. RSS (Received Signal Strength) from each LED is measured.
5. Trilateration algorithm calculates user position based on RSS-to-distance mapping.
6. Position coordinates (x, y) are output relative to the room reference frame.

Type: System Diagram / Schematic (ISAC Signal Structure)
---
Components:
- Data Symbols: Communication payload modulated onto the optical carrier.
- Pilot/Reference Symbols: Known sequences for channel estimation and positioning.
- Guard Interval (GI): Cyclic prefix or zero-padding to mitigate ISI.
- OFDM Frame Structure: Frequency-domain multiplexing of data and pilot subcarriers.

Structure:
- Frame Length: N symbols total.
- Pilot Density: Every Kth subcarrier reserved for sensing/positioning.
- Data Subcarriers: Remaining (N - N/K) subcarriers carry communication data.
- Time-Frequency Grid: Pilots placed in a comb pattern across frequency; data fills remaining slots.

Trend:
- Proposed ISAC method achieves best positioning accuracy, with >40% improvement over pure TOA at 90th percentile.

Type: Chart (BER vs SNR with Positioning)
---
Axes:
- X-axis: SNR (dB). Range: 0 to 30 dB.
- Y-axis: BER. Range: 10^-6 to 10^0 (Log scale).

Legend:
- Communication-only (Blue dashed): No pilots allocated for positioning.
- 10% Pilot Overhead (Red): 10% of subcarriers used for positioning.
- 20% Pilot Overhead (Green): 20% of subcarriers used for positioning.
- 30% Pilot Overhead (Orange): 30% of subcarriers used for positioning.

Data Points:
- Communication-only: BER = 10^-3 at SNR = 12 dB.
- 10% Pilot Overhead: BER = 10^-3 at SNR = 13 dB (1 dB penalty).
- 20% Pilot Overhead: BER = 10^-3 at SNR = 14.5 dB (2.5 dB penalty).
- 30% Pilot Overhead: BER = 10^-3 at SNR = 16 dB (4 dB penalty).

Trend:
- Increasing pilot overhead for positioning degrades communication BER due to reduced spectral efficiency.
- Trade-off: Each 10% pilot increase costs approximately 1.5 dB in required SNR.
