---
Components:
- Ground Station: Optical terminal, RF backup.
- FSO Link: 1550 nm, 10 km reach.
- RF Link: 60 GHz, 5 km backup.
- HAP (High Altitude Platform): Relay node.
- LEO Satellite: Inter-orbit link.
- User Terminals: Ground vehicles, UAVs.
- Radar Target: Aircraft.
- Weather Sensor: Atmospheric monitoring.

Sub-components:
- Tracking Gimbal: 2-axis, ±60° FoV.
- Adaptive Optics: Tip-tilt correction.
- Hybrid Combiner: FSO/RF switching.
- SDN Controller: Link selection logic.

Flow:
1. Ground Station → FSO/RF → HAP → LEO Satellite.
2. HAP: Sensing radar + relay communication.
3. Weather feedback → SDN → Dynamic link switching.

Image: _page_1_Figure_2.jpeg
Type: System Diagram / Schematic (FSO-RF Handover Architecture)
---
Components:
- Primary FSO Tx: 1550 nm, 20 dBm.
- Backup RF Tx: 60 GHz, 15 dBm.
- FSO Rx: InGaAs APD, -40 dBm sensitivity.
- RF Rx: Schottky mixer.
- Handover Controller: FSM (Finite State Machine).
- Weather Monitor: Visibility sensor.
- Dual-feed Antenna: Combined FSO/RF aperture.

State Diagram:
- State 1 (Clear): FSO only, BER < 10^-9.
- State 2 (Degraded): FSO + RF diversity, BER < 10^-6.
- State 3 (Outage): RF only, BER < 10^-3.
- Hysteresis: 5 dB margin for switching.

Flow:
1. Weather Monitor → Visibility check.
2. Controller: If visibility < 2 km → Switch to State 2/3.
3. Dual-path combining or single-path selection.
