# O_ISAC_136 Visual Analysis

## Image 1: _page_1_Picture_5.jpeg
- **Type**: Illustration / Energy Diagram
- **Description**: Rydberg atomic receiving mechanism.
- **Key Data**:
    - (a) Energy-level diagram: Ladder model ($S_{1/2} \to S_{3/2} \to nD_{5/2} \leftrightarrow (n+1)D_{3/2}$).
    - (b) Schematic showing vapor cell with counter-propagating Probe (red) and Coupling (green) lasers.
    - Noise sources identified: $n_{PSN}$ (Photon Shot Noise), $n_{BGN}$ (Background Noise), $n_{QPN}$ (Quantum Projection Noise).

## Image 2: _page_2_Figure_0.jpeg
- **Type**: System Block Diagram
- **Description**: Transceiver diagram of broadband RYDAR-based ISAC framework.
- **Components**:
    - ISAC Transmitter: Modulator -> Mixer -> DAC -> HPA -> TX Antenna.
    - ISAC Receiver (RYDAR): RF/LO source splitter -> Phase Shifter/Attenuator -> LO Antenna.
    - Vapor Cell: Interaction zone for Probe/Coupling lasers and RF/LO fields.
    - Readout: PD (Photodetector) -> LIA (Lock-In Amplifier) -> ADC -> Demodulator/Radar Sensing.
    - AOFS: Acousto-Optic Frequency Shifter for small-scale coupling laser modulation.

## Image 3: _page_2_Figure_2.jpeg
- **Type**: Chart / Graph
- **Description**: Comparison of PD output and LIA output showing RYDAR signal processing.
- **Extracted Content**:
    - RF OFF: Single EIT peak in PD output; LIA output shows its gradient.
    - RF ON: Autler-Townes (AT) splitting of the EIT peak; LIA output (red) provides a clear differential signal for Rabi frequency calculation.

## Image 4: _page_3_Figure_0.jpeg
- **Type**: Chart / Graph / Photograph
- **Description**: Proof-of-concept experimental results and laboratory setup.
- **Key Data**:
    - (a) Radar Ranging: Normalized amplitude vs Distance R [m]. Shows clear peaks for different target ranges. RMSE = 1.04 cm, Resolution ~15 cm.
    - (b) Communication: Symbol Error Rate vs SIR [dB]. Compares Without solver, LMS, LSTM, and ADRH solvers. Image quality improves significantly with SIR > 10 dB.
    - (c) Lab Setup: Cesium (Cs) vapor cell in an anechoic chamber with SIG and LO antennas.
