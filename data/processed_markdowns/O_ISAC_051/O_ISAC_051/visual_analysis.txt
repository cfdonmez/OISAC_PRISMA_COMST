Type: System Diagram / Schematic (Multi-Panel: Full-Duplex Optical ISAC Transceiver)
---
Components:
Panel (a) - Transmitter:
- ECL (External Cavity Laser): Narrow linewidth CW source.
- AWG (Arbitrary Waveform Generator): 120 GSa/s digital waveform generation.
- DAC: 8-bit resolution.
- I/Q Modulator: Dual-parallel MZM.
- EDFA: Booster amplifier (+23 dBm output).
- VOA: Variable optical attenuator.
- Polarization Controller: Launch polarization adjustment.

Panel (b) - Receiver:
- Circulator: 3-port Tx/Rx isolation.
- OBPF (Optical Bandpass Filter): ASE noise rejection.
- LO (Local Oscillator): From same ECL (homodyne).
- 90° Optical Hybrid: Coherent mixing.
- Balanced PDs: I/Q photocurrents.
- TIA: Trans-impedance amplifiers.
- ADC: 80 GSa/s, 8-bit.
- DSP: Offline processing.

Panel (c) - Fiber Link:
- SMF-28: Standard single-mode fiber.
- Target Reflector: Sensing endpoint.
- User Terminal: Communication endpoint.

Flow:
1. ECL → I/Q Mod → EDFA → VOA → Circulator (Port 1→2).
2. Circulator Port 2 → SMF → Target/User.
3. Reflected/returned signal → Circulator Port 2→3.
4. OBPF → 90° Hybrid (with LO from ECL).
5. Balanced PDs → TIA → ADC → DSP.
