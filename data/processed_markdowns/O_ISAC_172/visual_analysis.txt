## Image: _page_3_Figure_10.jpeg
### Type: Signal Flow Diagram (Sliding-Windows Normalization)

### Input Signal (I):
- Periodic power fading from DFB laser
- Amplitude variation due to frequency sweep
- Communication signal superimposed

### Processing Steps:
1. Segment by sliding window (size l)
2. Min-max normalization per segment
3. i_out = Σ (i_k - min(i_k)) / (max(i_k) - min(i_k))

### Output Signal (II):
- Uniform amplitude distribution
- Communication information preserved
- Periodic fading suppressed

### Algorithm Complexity:
- O(n) time complexity
- Real-time processing on DSP/FPGA

### O-ISAC Relevance:
- Enables IMDD communication with swept laser
- Critical for system performance
