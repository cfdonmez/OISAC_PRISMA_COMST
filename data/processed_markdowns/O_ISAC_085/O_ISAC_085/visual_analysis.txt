Type: Kalman Smoother (KS) Algorithm Schematic
---
**Components & Flow:**
* **Forward Filter Pass:**
    - Input: Phase Difference $\Delta \theta_{CPE}[i]$.
    - Steps: Forward Prediction -> Priori Variance Calculation -> Expected Measurement Calculation -> Kalman Gain Calculation -> Update Estimation -> Update Uncertainty Covariance. (Iterative $i=i+1$).
* **Backward Filter Pass:**
    - Input: Phase Difference $\Delta \theta_{CPE}[j]$.
    - Steps: Same as Forward but in reverse time $(j=j-1)$.
* **Smoother Pass:**
    - Combines outputs from Forward and Backward passes.
    - Components: Uncertainty Covariance Combination and Estimated Results Combination.
* **Final Processing:** Integration block to recover the total vibration-induced phase $\theta_{vib}$.

Type: Experimental Setup and Signal Spectra
---
**Components:**
* **Transmitter (Tx):** ~100 kHz External Cavity Laser (ECL), DP-IQ Modulator, RF Amplifier, Arbitrary Waveform Generator (AWG).
* **Link:** 20-25 km Standard Single Mode Fiber (SSMF), PZT (Piezoelectric Transducer for vibration), VOA (Variable Optical Attenuator).
* **Receiver (Rx):** EDFA, Local Oscillator (~100 kHz ECL), Integrated Coherent Receiver (ICR), 64 GSa/s Real-time Oscilloscope (RTO).
* **DSP Blocks (Tx):** PRBS, 16 QAM Mapping, Nyquist Shaping, Subcarrier Mux, Frequency-Pilot Tones (FPTs) Insertion.
* **DSP Blocks (Rx):** Dynamic FOE, CPE, Pol. DeMux, Subcarrier DeMux, Equalization (Communication path); KS-based Phase Extraction (Sensing path).
**Spectra (b & c):**
* **X-axis:** Frequency (GHz, -30 to 30).
* **Y-axis:** Power (dB/Hz, -200 to -50).
* **Details:** Displays the 16QAM signal bandwidth (approx 40 GHz) and distinct FPT spikes used for phase tracking in X and Y polarizations.
