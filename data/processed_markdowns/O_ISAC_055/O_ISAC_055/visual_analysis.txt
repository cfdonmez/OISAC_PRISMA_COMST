**Components:**
- **Device A (Left Block):** Sensing Transceiver & Communication Transmitter.
    - **Tx Chain:** Binary Data -> CPM Modulator -> Mixer (X) with LFM Generator -> Up Conversion -> Real part (R) -> Summation (+) with DC bias -> Laser Driver -> LED Array.
    - **Sensing Rx Chain:** Photodetector (receiving Reflected Sensing Signal) -> BPF -> Down Conversion -> Cross Correlation (with LFM Generator) -> Target Distance output.
- **Device B (Right Block):** Communication Receiver.
    - **Rx Chain:** Photodetector (receiving Transmitted ISAC Signal) -> BPF -> Down Conversion -> CPM Demodulator -> Binary Data output.
    - **Sync:** Synchronization block feeds LFM Generator relative to Down Conversion.
- **Channel:** Reflector with "Reflected Sensing Signal" (Blue) and "Transmitted ISAC Signal" (Orange).

**Flow:**
The diagram illustrates a dual-function ISAC system using LFM-CPM (Linear Frequency Modulation - Continuous Phase Modulation).
1.  **Transmission:** Device A modulates binary data using CPM, mixes it with a generated LFM chirp, upconverts it, and drives an optical source (LEDs).
2.  **Sensing:** The signal reflects off a target. Device A receives the reflection, downconverts it, and cross-correlates it with the local LFM reference to estimate target distance (Radar function).
3.  **Communication:** Device B receives the line-of-sight signal, downconverts it, synchronizes using the LFM component, and demodulates the CPM signal to recover the binary data.

- **Key Features:**
    - The distance d^2_min fluctuates with h.
    - **Local Minima:** Explicitly marked at integers h=2 and h=4, where the distance drops significantly (collapse of signal constellation).
    - **Maxima:** Performance peaks around non-integer values (e.g., h ~ 1.7, h ~ 2.7).
    - **Convergence:** As N increases, the curve converges towards the upper bound structure but retains deep nulls at integers.

**Legend/Trends:**
- **Variables:** Sensing/Comm Performance Metric (d^2_min) vs Modulation Index (h) for different sequence lengths (N).
- **Trend:** To maximize performance (d_min), one must avoid integer modulation indices (h=1, 2, 3...) where the minimum distance collapses. Optimal operating points are likely around h=X.75 or X.25.

**Axes Extraction:**

- **Y-axis:** Ranging RMSE (m) [Range: 10^-2 to 10^1] (Log scale)

    - RMSE ~ 10^-1.8 m at 5 dB.
    - RMSE ~ 0.5 * 10^-2 m at 14 dB.
- **Comparison:** h=3.875 (Yellow/Red curves) provides LOWER RMSE (better sensing accuracy) than h=1.75 (Blue/Purple curves). This contradicts the communication performance where h=1.75 was better, illustrating the sensing-communication trade-off.

**Legend/Trends:**
- **Variables:** Ranging RMSE vs SNR for different h values.
- **Trend:** Higher modulation index (h) improves ranging accuracy (likely due to wider bandwidth or better correlation properties) but degrades communication reliability (as seen in Figure 16).
