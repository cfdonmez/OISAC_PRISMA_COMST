TYPE: System Diagram / Structure
DESCRIPTION: Architecture of the ISAC OPA-based Lidar system and antenna design.
PANELS:
- (a) System Architecture: 
  - TX Terminal: Laser -> PC -> MZM (driven by AWG/QPSK-LFM Joint Waveform) -> EDFA -> Splitter -> TX OPA.
  - Lidar RX: RX OPA -> Coherent Receiver (LO input from Splitter) -> OSC -> Target Detection.
  - Commun. RX: PD -> TIA -> Mixer (ELO input) -> LPF -> OSC -> DSP-based Data Recovery.
- (b) OPA Antenna Array: Thinned ring array layout with "Full ring" and "Thinned ring" elements highlighted.
- (c) Blazed Grating Antenna: Single element detail with L=2.8 um, W=1.2 um, and "Shallow etch" features.
