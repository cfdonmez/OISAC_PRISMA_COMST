## Image: _page_3_Picture_15.jpeg
### Type: Waveform Diagram

### Title: One Symbol of Co-FMCW-OFDM Waveform

### Structure:
- OFDM symbol: [CP | Data]
- FMCW symbol: [Zero CP | Chirp | Zero guard]
- Same duration: Tsym = T + Tcp
- Synchronized in symbol level

### Key Design:
- All-zero CP for FMCW
- Enables FCCR algorithm
- Reduces inter-symbol interference

### Parameters:
| Parameter | Description |
|-----------|-------------|
| Bw | Bandwidth |
| Tc | Chirp duration = T - Tcp |
| N | IFFT size (4096) |
| Ncp | CP length (288) |
