### Image Analysis: OWC-based JCAP System Setup
**File:** _page_1_Picture_1.jpeg
**Type:** System Diagram / Schematic
**Components:**
- **Transmitter Side (Base Station - BS):** 
  - Optical Line Terminal (OLT).
  - Power Lines / Network Connection.
  - Optical Fiber connecting BS to Remote Radio Head (RRH) / Access Point.
  - Visible Light Transmitters (LED Array).
- **Communication Link:**
  - Optical Wireless Channel (OWC).
  - Signal: Joint Communication and Positioning (JCAP) signal.
- **Receiver Side (User Device - UD):**
  - Optical Receiver (Photodetector - PD).
  - Integrated Circuitry for signal processing.
- **Signal Flow:** 
  1. Data from BS is modulated and sent via LEDs.
  2. UD receives the optical signal.
  3. Integrated sensing/positioning algorithm estimates UD location based on Received Signal Strength (RSS) or Time of Flight (ToF) metrics.
- **Context:** JCAP system for simultaneous data transmission and high-precision indoor positioning.

### Image Analysis: UD Localization Error vs LEM Error
**File:** _page_0_Figure_11.jpeg
**Type:** Chart / Graph
**Axes:**
- **X-axis:** Lambertian Emission Model (LEM) Error (unit-less factor or degrees).
- **Y-axis:** User Device (UD) Localization Error (cm).
**Data Points:**
- Trend: Linear or near-linear increase.
- For LEM error of ~0.1, UD localization error is ~2-3 cm.
- For LEM error of ~0.5, UD localization error increases to ~10-12 cm.
**Findings:** High sensitivity of positioning accuracy to the accuracy of the LED radiation pattern model.

### Image Analysis: Convergence of MM-based JCAP Algorithm
**File:** _page_4_Figure_11.jpeg
**Type:** Chart / Graph
**Axes:**
- **X-axis:** Number of Iterations.
- **Y-axis:** Objective Function / Convergence Metric.
**Data Points:**
- Method: Majorization Minimization (MM) based algorithm.
- Initial value: ~10^2.
- Final value: Stabilizes at ~10^-1 after 15-20 iterations.
**Findings:** The proposed MM algorithm converges rapidly, achieving stable positioning results within a few iterations.

### Image Analysis: VLP Error vs SNR
**File:** _page_4_Figure_13.jpeg
**Type:** Chart / Graph
**Axes:**
- **X-axis:** Signal-to-Noise Ratio (SNR) (dB). Range: 0 to 40 dB.
- **Y-axis:** Visible Light Positioning (VLP) Error (cm). Range: 10^1 to 10^-2 (log scale).
**Legends:**
- Proposed JCAP Method.
- Conventional RSS-based Method.
- Conventional ToF-based Method.
**Data Points:**
- At SNR = 20 dB: JCAP Error ~ 1 cm; RSS ~ 10 cm.
- At SNR = 40 dB: JCAP Error ~ 0.1 cm (1 mm); RSS ~ 2 cm.
**Findings:** JCAP significantly outperforms conventional methods, achieving sub-centimeter accuracy at high SNR.

### Image Analysis: VLP Error vs Initial LEM Error
**File:** _page_5_Figure_1.jpeg
**Type:** Chart / Graph
**Axes:**
- **X-axis:** Initial LEM Error.
- **Y-axis:** VLP Error (cm).
**Legends:**
- JCAP (Proposed).
- Baseline (Non-JCAP).
**Data Points:**
- JCAP error remains relatively flat (~1-2 cm) regardless of initial LEM error.
- Baseline error increases sharply from ~2 cm to >10 cm as LEM error increases.
**Findings:** The JCAP method is robust to initial model inaccuracies due to its joint calibration capability.

### Image Analysis: VLP Error vs Subcarrier Frequency
**File:** _page_5_Figure_3.jpeg
**Type:** Chart / Graph
**Axes:**
- **X-axis:** Subcarrier Frequency (MHz). Range: 1 to 100 MHz.
- **Y-axis:** VLP Error (cm).
**Data Points:**
- Error decreases from ~5 cm at 1 MHz to <1 cm at 100 MHz.
**Findings:** Higher subcarrier frequencies provide better time resolution, directly translating to improved positioning accuracy.
