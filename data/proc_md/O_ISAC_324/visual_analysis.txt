## Image: _page_4_Figure_6.jpeg
### Type: Concept Diagram

### Title: ISAQN Sensing Principle

### Panel (A) - No Vibration:
- Normal QKD operation
- Coherent state $|\alpha_i\rangle$ returns unchanged (phase wise)

### Panel (B) - Vibration Event:
- Vibration induces phase rotation $\varphi_i(t)$
- State becomes $|\alpha_i\rangle e^{j\varphi_i(t)}$
- Sensing via phase monitoring

### Type: Signal Processing Schematic

### Title: Time-Frequency Domain Processing

### Flow:
1. Child nodes modulate QKD + Pilot signals (TDM) on different carriers (FDM)
2. Fiber transmission (Vibration adds modulation)
3. Detection at Center Node
4. Spectrum Castdown (backscattering) + Spectrum Splitting (pilot)
5. SPM Protocol: Coherent Demodulation -> Phase Unwrapping -> Waveform Recovery

### Key Concept:
- Simultaneous QKD and Sensing extraction from same signal
