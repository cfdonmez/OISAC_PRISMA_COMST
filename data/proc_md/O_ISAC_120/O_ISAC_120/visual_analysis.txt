Type: System Diagram / Schematic (Dual-Comb ISAC Transceiver)
---
Components:
- OFC 1: Optical Frequency Comb 1 (Signal), 100 MHz rep rate.
- OFC 2: Optical Frequency Comb 2 (LO), 100 MHz + Δf (1 kHz offset).
- EDFA ×2: Erbium-doped fiber amplifiers (23 dBm each).
- IQ Modulator: 40 GHz bandwidth, data encoding.
- Circulator: High isolation Tx/Rx routing.
- Collimator: Free-space coupling.
- Target: Distributed reflectors.
- Balanced PD: Dual-comb heterodyne detection.
- ADC: 250 MSa/s (downconverted RF).
- DSP: Multi-carrier processing.

Flow:
1. OFC 1 → IQ Mod (OFDM data) → EDFA → Circulator → Collimator → Target.
2. Return signal → Collimator → Circulator.
3. OFC 2 (LO) + Return → Balanced PD (multi-heterodyne).
4. ADC → DSP (range, velocity, data extraction).

Key Parameters:
- 50 comb lines (5 THz span).
- 100 GHz line spacing.
- Effective sensing BW: 5 THz.
