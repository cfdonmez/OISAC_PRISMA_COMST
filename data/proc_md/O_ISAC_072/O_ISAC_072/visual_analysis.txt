**Components:**
- **(a) Training Phase:**
    - Sensing Background Noise Generation (Frequency Tone (FPTs) Extraction, Data Block, Frequency Offset Estimation, Polynomial Fitting, etc.).
    - Digital Simulation (Random Sine Wave for vibration-induced phase).
    - Artificial Neural Network (ANN) with Adam Optimizer and Smooth L1 Loss.
- **(b) Application Phase:**
    - FPTs-based Carrier Recovery (Experimental Received Data With Vibration).
    - ANN processing to extract phase.
    - Low-pass Filter for final output.

**Flow:**
In phase (a), experimental noise is combined with simulated vibration data to train an ANN using the Smooth L1 Loss function. In phase (b), the trained ANN is used to process real-time experimental data containing vibrations. The ANN acts as a powerful phase extractor, followed by a low-pass filter to provide a clean vibration signal signature.

Type: System Diagram / Experimental Schematic

**Components:**
- **Transmitter:** ~100 kHz ECL (External Cavity Laser), DP-IQ Modulator, AWG, RF Amplifier.
- **Link:** SSMF (Standard Single Mode Fiber), PZT (Piezoelectric Transducer - for vibration induction).
- **Receiver:** VOA (Variable Optical Attenuator), EDFA, ~100 kHz ECL (Local Oscillator), ICR (Integrated Coherent Receiver), 64 GSa/s RTO (Real-Time Oscilloscope).
- **DSP Blocks:**
    - **Tx-DSP:** PRBS, 16 QAM Mapping, Nyquist Shaping, Subcarrier Mux, FPTs (Frequency Pilots) Insertion.
    - **Rx-DSP:** FPT-based Dynamic FOE/CPE.
    - **Communication path:** Pol. DeMux, Subcarrier DeMux, Equalization, Decision.
    - **Sensing path:** Down Sampling, ANN, Low-Pass Filter.

**Flow:**
Optical signals from an ECL are modulated with 16QAM data and Frequency Pilots (FPTs). The signal propagates through 20km SSMF and is subjected to vibrations by a PZT. At the receiver, coherent detection is used. The Rx-DSP splits the signal into two paths: one for 16QAM communication recovery and another using an ANN to extract the PZT-induced vibration frequency for sensing.
