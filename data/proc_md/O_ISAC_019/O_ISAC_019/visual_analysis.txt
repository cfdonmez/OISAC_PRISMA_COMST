# Visual Analysis for O_ISAC_019

## Figure 1: Full-Duplex Microwave Photonics ISAC Architecture
**File:** [_page_1_Figure_0.jpeg](file:///g:/Drive'ım/AKU_WorkSpace/survey_fdgit/OISAC_PRISMA_COMST/data/proc_markdowns/O_ISAC_019/O_ISAC_019/_page_1_Figure_0.jpeg)
- **Type:** System Schematic.
- **Central Office (CO):** Multi-wavelength source (LD1-LDn) -> WDM multiplexer -> Phase Modulator (PM) for downlink -> Demux -> Real-time Delay Module (Beamforming) -> Fiber.
- **Remote Antenna Unit (RAU):** Recovers downlink via Band-Stop Filter and PD; reuses optical carrier for uplink via Intensity Modulator (MZM).
- **Communication Flow:** Simultaneous bidirectional fiber transport using different modulation formats (PM for DL, IM for UL/Echo) over the same carrier.

## Figure 2: Frequency Resource Allocation
**File:** [_page_2_Figure_0.jpeg](file:///g:/Drive'ım/AKU_WorkSpace/survey_fdgit/OISAC_PRISMA_COMST/data/proc_markdowns/O_ISAC_019/O_ISAC_019/_page_2_Figure_0.jpeg)
- **Type:** Spectrum Allocation Diagram.
- **Millimeter-Wave Bands (mmW):** 71-76 GHz (Uplink), 76-81 GHz (Automobile Radar), 81-86 GHz (Downlink).
- **Intermediate Frequency (IF) Mapping:**
  - **Downlink (DL):** 13-18 GHz (IF) $\xrightarrow{\text{LO=68GHz}}$ 81-86 GHz (mmW).
  - **Uplink (UL):** 71-76 GHz (mmW) $\xrightarrow{\text{LO=68GHz}}$ 3-8 GHz (IF).
  - **Radar Echo:** 81-86 GHz (mmW) $\xrightarrow{\text{LO=68GHz}}$ 13-18 GHz (IF).
- **Isolation:** USes a Duplexer at CO to separate the Uplink IF (3-8 GHz) and Radar Echo IF (13-18 GHz).
