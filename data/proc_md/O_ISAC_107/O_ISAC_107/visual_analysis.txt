Image: _page_2_Figure_2.jpeg
Type: System Diagram / Schematic (Coherent ISAC Transceiver with Machine Learning)
---
Components:
- ECL: External Cavity Laser at 1550.12 nm, linewidth <100 kHz.
- IQ Modulator: Dual-parallel MZM for coherent modulation.
- DAC: 84 GSa/s digital-to-analog converter.
- EDFA: 23 dBm output power.
- Circulator: High isolation Tx/Rx routing.
- Collimator: Free-space beam forming.
- Target: Distributed reflectors.
- 90° Hybrid: Coherent receiver front-end.
- Balanced PDs: 4-channel balanced photodetectors.
- ADC: 100 GSa/s real-time digitizer.
- ML Engine: Neural network inference unit (GPU/FPGA).
- DSP: Joint radar-comm signal processing.

Flow:
1. ECL → IQ Mod (data from DAC) → EDFA → Circulator → Collimator.
2. Free-space propagation to Target.
3. Return signal → Collimator → Circulator → 90° Hybrid.
4. LO from ECL → 90° Hybrid → Balanced PDs → ADC.
5. ADC → ML Engine (target classification) → DSP (parameter extraction).

Type: System Diagram / Schematic (ML-Assisted Signal Processing Pipeline)
---
Components:
- Input Layer: Raw IQ samples (complex).
- Feature Extraction: FFT, range-Doppler, constellation.
- CNN Block: 5-layer convolutional network.
- LSTM Block: Temporal sequence processing.
- Fusion Layer: Multi-task attention mechanism.
- Output Heads: [Range, Velocity, Angle, Communication Symbols].

Architecture Details:
- CNN: 64-128-256-256-128 filters.
- LSTM: 2 layers, 256 hidden units.
- Training samples: 500,000.
- Inference latency: 2.5 ms per frame.
