Type: System Diagram / Schematic (Multi-Panel: Photonic Integrated ISAC Transceiver)
---
Components:
Panel (a) - PIC Layout:
- Tunable Laser: On-chip III-V/Si hybrid laser.
- MZM Array: 4-channel parallel modulators.
- MMI Coupler: Multi-mode interference splitter/combiner.
- Grating Couplers: Fiber-to-chip interfaces.
- Photodetector Array: Ge-on-Si PDs.
- Heaters: Thermo-optic phase tuners.
- Wire Bonds: Electrical interconnects.

Panel (b) - Block Diagram:
- TX DSP: Waveform generation (OFDM + sensing pilots).
- DAC: 4-channel, 64 GSa/s.
- Driver Amplifiers: RF gain stages.
- PIC: Photonic integrated circuit.
- EDFA: External optical amplifier.
- Circulator: Tx/Rx separation.
- RX PIC: Coherent receiver on-chip.
- TIA Array: Trans-impedance amplifiers.
- ADC: 4-channel, 80 GSa/s.
- RX DSP: Joint demodulation and sensing.

Panel (c) - Chip Photograph:
- Die size: 4.5 mm × 6.2 mm.
- Technology: Si-photonics 45nm SOI.
- Fiber array coupling visible.

Flow:
1. TX DSP → DAC → Driver → MZM Array on PIC.
2. Optical signals combined via MMI → EDFA.
3. Circulator routes to fiber link.
4. Return signal → Circulator → RX PIC.
5. On-chip coherent detection → TIA → ADC → RX DSP.

Type: Chart (BER vs Received Optical Power for ISAC)
---
Axes:
- X-axis: Received Optical Power (dBm). Range: -25 to -5 dBm.
- Y-axis: BER. Range: 10^-6 to 10^-1 (log scale).

Legend:
- Comm Only (Blue circles): No sensing overhead.
- ISAC 10% (Red squares): 10% sensing pilots.
- ISAC 20% (Green triangles): 20% sensing pilots.
- ISAC 30% (Orange diamonds): 30% sensing pilots.
- HD-FEC Threshold (Black dashed): BER = 3.8×10^-3.

Data Points:
- Comm Only at HD-FEC: -20 dBm.
- ISAC 10% at HD-FEC: -19 dBm (1 dB penalty).
- ISAC 20% at HD-FEC: -17.5 dBm (2.5 dB penalty).
- ISAC 30% at HD-FEC: -15.5 dBm (4.5 dB penalty).

Trend:
- Power penalty scales ~1.5 dB per 10% sensing overhead.
- All configurations achieve BER 10^-4 at -10 dBm.
- Error floor not observed down to 10^-6.

- At SCS = 120 kHz: Range RMSE = 2.8 cm; Max Doppler = 2000 Hz.
- At SCS = 240 kHz: Range RMSE = 5.2 cm; Max Doppler = 4000 Hz.

Trend:
- Wider SCS improves Doppler range but degrades range accuracy.
- Sweet spot: 60 kHz SCS for balanced performance.
- Trade-off ratio: ~1 cm RMSE degradation per doubling of SCS.
