## Image 2: _page_1_Figure_2.jpeg

## Image 3: _page_2_Figure_0.jpeg
- **Type**: Technical Workflow / Pipeline
- **Description**: Pre-processing steps to transform bi-static RF data into mono-static format.
- **Steps**:
    1. **Spatial Transform**: $H_{CIR} (Tx \times Rx \times Delay)$ to $H_{beam} (AoA \times AoD \times Delay)$.
    2. **Remove LOS**: Eliminating the direct path to focus on reflections ($H'_{beam}$).
    3. **Project AoD to Delay**: Mapping multi-path components to mono-static delay $P_{RX}(\Theta_{AoA}, r_1)$.
    4. **Mono-static Power Scaling**: Scaling reflection power by $(r_1/r_2)^2$.
- **Result**: $P_{RX}(X, Y, Z)$ point cloud representation.

## Image 4: _page_3_Figure_0.jpeg
- **Type**: AI/ML Model Architecture
- **Description**: Deep Learning model for depth map estimation.
- **Layers**:
    - Input: $6400 \times 1$ (Mono-static power map).
    - Dense Layer: $4096 \times 1$ with Relu.
    - Reshape: $32 \times 32 \times 4$.
    - Upsampling: Factor (3,3,3) to $96 \times 96 \times 12$.
    - CNN Layer 1: Filter Size (13,13,2), 2 Filters, Relu.
    - CNN Layer 2: Filter Size (13,13,3), 4 Filters, Relu.
    - CNN Layer 3: Filter Size (9,9,2), 8 Filters, Sigmoid.
    - Final Reshape: Output Voxel Grid of $128 \times 128 \times 16$ voxels (resolution 0.25m).
