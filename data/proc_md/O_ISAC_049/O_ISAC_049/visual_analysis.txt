Type: System Diagram / Schematic (Fiber-Wireless ISAC Architecture)
---
Components:
- Central Office (CO): Contains optical transceiver and DSP.
- SMF (Single Mode Fiber): Connects CO to Remote Radio Head.
- RRH (Remote Radio Head): Optical-to-electrical conversion.
- Antenna Array: mmWave phased array for wireless transmission.
- Radar Processing Unit: Extracts sensing information.
- Communication Users: Mobile terminals receiving data.
- Sensing Targets: Objects detected by radar function.
- Fronthaul Link: Digital fiber connection.
- Backhaul: Connection to core network.

Flow:
1. CO generates joint radar-communication waveform.
2. Signal transmitted over SMF to RRH.
3. RRH performs O/E conversion and frequency upconversion.
4. Antenna Array transmits mmWave beam to users and targets.
5. Reflected signals from Sensing Targets captured.
6. Radar Processing Unit extracts range/velocity.
7. Communication data delivered to mobile users.

Type: System Diagram / Schematic (OFDM Radar Waveform Concept)
---
Components:
- OFDM Symbol Grid: Time-frequency resource block.
- Pilot Subcarriers: Reference signals for sensing.
- Data Subcarriers: Communication payload.
- Guard Subcarriers: Edge protection.
- Cyclic Prefix: Inter-symbol interference mitigation.

Description:
- Resource grid shows N_FFT = 1024 subcarriers.
- Pilot spacing: Every 4th subcarrier (Δf_pilot = 60 kHz).
- Symbol duration: T_s = 16.67 µs (60 kHz SCS).
- CP duration: T_CP = 4.69 µs.
- Total symbol: 21.36 µs.
- Sensing pilots embedded within communication frame.

Type: Chart (Multi-Panel: ISAC Waveform Comparison)
---
Panel (a) - Time-Domain Waveform:
Axes:
- X-axis: Time (µs). Range: 0 to 100 µs.
- Y-axis: Amplitude. Range: -1 to +1 (normalized).

Observations:
- OFDM: Gaussian-like amplitude distribution (high PAPR).
- FMCW: Constant envelope chirp.
- DFRC: Hybrid with data-modulated chirp.

Panel (b) - Power Spectral Density:
Axes:
- X-axis: Frequency (MHz). Range: -500 to +500 MHz.
- Y-axis: PSD (dBm/Hz). Range: -80 to -40 dBm/Hz.

Data Points:
- OFDM: Flat spectrum within 400 MHz bandwidth, -45 dBm/Hz in-band.
- FMCW: Uniform power across chirp bandwidth, -48 dBm/Hz.
- DFRC: Similar to FMCW with slight notches at data transitions.

Panel (c) - Ambiguity Function:
Observations:
- OFDM: Thumbtack ambiguity (good range-Doppler separation).
- FMCW: Diagonal ridge (range-Doppler coupling).
- DFRC: Compromise between OFDM and FMCW characteristics.
