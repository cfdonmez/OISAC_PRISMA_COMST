## Image: _page_2_Figure_8.jpeg
### Type: Signal Comparison

### Title: Two 8th-Order MLS Signals with Different PPC Codes

### Signals:
- PPC code 100011101 (index 0)
- PPC code 100101011 (index 1)
- Length L = 2^8 - 1 = 255

### Key Feature:
- Same correlation properties
- Distinct waveforms
- Enables CIM (Code Index Modulation)

### CIM Capacity:
- n = 8: 16 PPC codes available
- 4 index bits per OFDM-MLS symbol

### O-ISAC Relevance:
- CIM adds data without sensing penalty

### Panel (b) - α = 0.3:
- VPP allocation ratio = 0.3
- 70% OFDM, 30% MLS
- More visible MLS structure
- Better sensing

### Key Equation:
x = α·x_MLS + (1-α)·x_OFDM

### Fixed Parameters:
- Total VPP = 2V (constant)
- α = 0: Pure OFDM
- α = 1: Pure MLS
