## Image: _page_4_Figure_2.jpeg
### Type: Experimental Setup Diagram

### Title: Photonic LFM-BPSK THz-ISAC System Schematic

### Components:
- **Optical Source:** ECL (1552 nm) -> PM (Comb Generator) -> WSS (Filter).
- **Transmitter:**
  - Lower Branch: EDFA -> IQ-MOD (Driven by AWG LFM-BPSK).
  - Upper Branch: LO (Local Oscillator).
  - Photomixing: Coupler -> UTC-PD (Uni-Traveling Carrier Photodiode).
- **Receiver:**
  - THz Antenna -> THz LNA -> Schottky Mixer -> DSO.
- **Processing:** Digital Down Conversion -> Radar/Comms DSP.

### Frequency Plan:
- Optical LO separation: 330 GHz.
- Output Frequency: 330 GHz Band (THz).

### O-ISAC Relevance:
- State-of-the-art Photonics-based THz ISAC prototype.

### Title: Range Profile vs Data Rate

### Visuals:
- Main lobe width (Resolution) unchanged.

Key Technical Findings:
1. **Radar-Centric Waveform:** LFM-PSK preserves LFM envelope (good for PA efficiency) but carries data.
2. **Sensing Improvement:** Embeddding random BPSK data improves Peak Sidelobe Ratio (PSLR) by ~6 dB (from 14.5 to 20.9 dB).
3. **Performance Specs:**
   - Carrier: 330 GHz (spans 324-336 GHz, BW = 12 GHz).
   - Range Resolution: 1.3 cm (Theoretical), 1.5 cm (Experimental).
   - Data Rate: 6 Gbit/s (BPSK).
   - PSLR: ~21 dB.

Key Innovations:
1. Photonics-based generation of high-frequency (330 GHz) wideband (12 GHz) LFM-PSK.
2. Demonstrating that Comms data can *enhance* Radar performance (PSLR) rather than degrade it (as in ASK).
