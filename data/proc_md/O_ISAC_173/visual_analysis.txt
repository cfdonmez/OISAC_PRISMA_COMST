## Image: _page_1_Figure_15.jpeg
### Type: Conceptual Diagram (OCC Spatial Multiplexing)

### Concept:
- Camera sensor isolates signals from multiple transmitters
- Each transmitter maps to unique pixel region
- Equivalent to optical receiver-side beamforming
- Millions of pixels → fine spatial resolution

### Key Advantage:
- Simultaneous reception across all FOV
- Quasi-orthogonal point-to-point channels
- Minimal interference between transmitters

### O-ISAC Relevance:
- Spatial multiplexing for optical ISAC
- Localization via angle-of-arrival

## Image: _page_2_Figure_2.jpeg
### Type: System Architecture Diagram (HP-OCC Receiver)

### Components:
- **SPAD Sensor Array:**
  - Single-photon avalanche diodes
  - High temporal resolution
  - Event-based photon detection

- **Crossbar Network:**
  - Dynamic pixel-to-processor assignment
  - Tracks transmitter across sensor

- **Edge Processing Units Pool:**
  - Multiple parallel processors
  - Each demodulates single optical stream
  - OOK/ASK demodulation capable

### Signal Flow:
- Photon arrival → SPAD event
- Crossbar routes to assigned processor
- Edge unit decodes optical stream

### Modulation Support:
- OOK (On-Off Keying)
- ASK (Amplitude Shift Keying)

### O-ISAC Relevance:
- Frameless architecture for high speed
- Simultaneous communication + localization

## Image: _page_3_Picture_1.jpeg
### Type: Hardware Photo (Passive Transmitter Tag)

### Components:
- Solar panel (power harvesting)
- Retroreflector (reflects incoming light)
- LC shutter (modulates light with tag ID)
- Microcontroller (controls modulation)

### Operation:
- No dedicated power source required
- Interrogation light from receiver
- Tag modulates reflected light with ID

### Challenge:
- 100 Hz flicker from mains LED lighting
- Resolved with higher optical data rates
- Range limited by LC shutter speed

### O-ISAC Relevance:
- Passive optical sensing tags
- Alternative to RFID/BLE
