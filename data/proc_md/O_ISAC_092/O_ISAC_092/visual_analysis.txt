Type: ISAC Network Scenario
---
**Components:**
* **Transmitter (Tx):** Emitting $x(t)$.
* **Communication Receiver (Communication Rx):** Receiving $y_c(t)$.
* **Sensing Receiver (Sensing Rx):** Receiving $y_s(t)$ after reflection from the Target.
**Signal Flow:** The transmitted signal $x(t)$ splits: one path goes directly (or via a channel) to the Communication Rx, and the other path reflects off the Target back to the Sensing Rx.

Type: Signal Illustration (PAM)
---
**Structure:** Shows a sequence of Pulse Amplitude Modulation (PAM) symbols.
**Labels:**
* $T_b$: Symbol duration.
* $A_{M-1}, A_{M-2}, ..., A_1, A_0$: Amplitude levels.
* Formula: $A_0 = (1-\alpha) A_{M-1}$.
---

Image: _page_3_Figure_2.jpeg
Type: Signal Processing Block Diagram
---
**Flow:**
1. Input $x_n(\alpha_1)$ enters "Process 1" to yield $\hat{x}_n(\alpha_1) = x_n(\alpha_1) - A_{M-1}$.
2. Normalization block: $\hat{x}_n(\alpha_2) = \frac{\alpha_2}{\alpha_1} \hat{x}_n(\alpha_1)$.
3. Re-biasing: $x_n(\alpha_2) = \hat{x}_n(\alpha_2) + A_{M-1}$.
4. "Process 2" followed by the physical link: LED -> optical channel (with noise $w_n$) -> APD -> data process -> Output $y_{c,n}$.

Type: Dual Performance Chart (Rate and Divergence)
---
**Axes Extraction:**
* **X-axis:** SNR (dB) (0 to 30).
* **Y-axis (Top):** Achievable Transmission Rate [bit/symbol] (0 to 2).
* **Y-axis (Bottom):** KL Divergence ($10^{0}$ to $10^{2}$ log-scale).
**Trend:** As $\alpha$ increases from 0.2 to 1, the transmission rate increases significantly (e.g., at 15 dB, $\alpha=1$ gives ~1.7 bit/symbol vs $\alpha=0.6$ giving ~0.6). Conversely, KL divergence is lower for higher $\alpha$.

---
**Axes Extraction:**

Type: Implementation Schematic
---
**Components:**
* **Transmitter:** DC Signal + AC Signal -> Signal Coupler -> LED.
* **Com-Receiver:** Com-Channel -> APD -> ADC -> Data Process.
* **Sen-Receiver:** Sen-Channel -> Target -> APD -> ADC -> Data Process.
**Flow:** LED transmits through two channels. One is a direct communication link. The other is a sensing link reflecting off a Target.
