### Key Components & Path Flow
1.  **Transmitter Side (Tx):**
    *   **Laser:** Source.
    *   **Tx DSP -> AWG:** Digital Signal Processing drives Arbitrary Waveform Generator.
    *   **DP-IQM:** Dual-Polarization IQ Modulator. Modulates Laser light with AWG signal.
    *   **SOA:** Semiconductor Optical Amplifier.
    *   **EDFA1:** Erbium-Doped Fiber Amplifier (Booster).
    *   **OBPF:** Optical Bandpass Filter.
2.  **Sensing Path Components:**
    *   **Cir. (Circulator):** Port 1 -> Port 2 -> Port 3.
    *   **FUT:** Fiber Under Test (connected to Port 2). Ends with **0.5m PZT** (Piezo-Electric Transducer for vibration emulation).
    *   **Return Path:** Reflected signal enters Port 2 -> Exits Port 3 -> **EDFA2** -> **Sensing DSP**.
3.  **Sensing DSP Block:**
    *   **ICR+DSO2:** Integrated Coherent Receiver + Digital Storage Oscilloscope.
    *   **DSP Functions:** "FOE, Match filter, Segment Sync., Delay&RVS, Phase unwrap".
4.  **Telecom Path Components (Downlink):**
    *   Signal passes through FUT? (Diagram suggests signal goes *through* FUT to Telecom part).
    *   **ECL:** External Cavity Laser (Local Oscillator).
    *   **Rx Telecom DSP:**
        *   **90deg Hybrid + BPD + DSO1:** Coherent detection front-end.
        *   **Offline Telecom DSP:** "Frame sync., CD comp., TS-aided FOE, CMA, TS-aided DD-LMS, EKF Decision".
5.  **Interference/Modulation Generation:**
    *   **MSG -> MZM -> EDFA3 -> WS:** A separate branch (possibly creating interference or a second channel?) feeding into the system via **WS** (Wavelength Selector/Switch?). *Correction: This path actually feeds backwards or into the loop? It connects to the Fiber link via a component triangle (Coupler/Amplifier) before EDFA2? Flow is ambiguous here but clearly an auxiliary modulation source.*

### Flow Description
A coherent optical system performing simultaneous sensing and communication.
*   **Sensing:** Uses backscattering/reflection from the FUT (via Circulator) to detect PZT vibration. Processed by **Sensing DSP**.
*   **Communication:** Transmits data through the FUT to a coherent receiver (**Telecom part**). Processed by **Telecom DSP**.
