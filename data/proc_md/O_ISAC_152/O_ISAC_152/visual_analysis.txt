Type: System Diagram / Schematic (THz Photonic ISAC System)
---
Components:
- CW Laser Pair: λ1 = 1550.0 nm, λ2 = 1550.8 nm (100 GHz offset).
- Optical Coupler: 3 dB.
- UTC-PD (Uni-Travelling Carrier Photodiode): THz generation.
- THz Antenna: Horn antenna, 26 dBi gain.
- Target Scene: Indoor environment.
- THz Receiver: Schottky diode mixer.
- LO: Local oscillator from same laser pair.
- IF Amplifier: 1-10 GHz bandwidth.
- ADC: 20 GSa/s.
- DSP: Joint radar-comm processing.

Sub-components:
- MZM: Data modulation on optical carrier.
- EDFA: Optical amplification before UTC-PD.
- Lens: THz focusing optics.

Flow:
1. Laser pair → Coupler → Beat at 100 GHz → UTC-PD.
2. MZM on λ1 for data → Combined with λ2 → THz carrier + data.
3. THz Antenna → Target → Reflected → THz Rx.
4. LO mixing → IF Amp → ADC → DSP.
