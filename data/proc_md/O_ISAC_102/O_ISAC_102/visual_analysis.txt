Type: System Schematic (Experimental/Simulation Setup)
---
**Components:**
* **WDM Transmitter / WDM Receiver:** End points.
* **OMU (Optical Multiplexer Unit) & ODU (Optical Demultiplexer Unit):** Aggregation/Dissagregation.
* **L1 & L2:** Fiber spans.
* **Pump Light Units:** "Amplifying Part of Pump light" and "Compensation Part of Pump light".
**Flow:** Transmitter -> OMU -> L1 -> ODU -> OMU (with Compensation) -> L2 -> ODU -> ODU -> Receiver. This setup focuses on Raman amplification (DRA) in a WDM system.

Image: _page_7_Figure_8.jpeg
Type: Optimization Flow Diagram
---
**Components:**
* **ABC algorithm (Artificial Bee Colony):** Optimization engine.
* **Input Parameters:** Wavelengths ($\lambda_{1-8}$) and Powers ($P_{1-8}$) for 8 pumps.
* **OMU:** Multiplexer.
* **Neural Network (Inset):** ANN model for gain/noise prediction.
* **ODU:** Demultiplexer.
* **G101:** Outcome metric (likely Gain flatness or target level).
**Description:** The ABC algorithm optimizes pump parameters ($\lambda, P$) which are fed through an ANN-based Raman amplifier model to achieve target performance ($G101$).
