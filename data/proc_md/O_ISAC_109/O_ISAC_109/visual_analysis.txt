Type: System Schematic (Fig. 1: Pipeline overview)
---
**Components:**
1. **Map Data:** Geographic input (OpenStreetMap) defining the intersection geometry.
2. **Physics Data Generation:** Vehicular traffic simulation using SUMO.
3. **Pointcloud Generation:** 3D dynamic environment rendering using Blender/Blensor.
4. **Vehicle Detection Algorithm:** Processing raw point cloud data to output potential object clusters.
5. **Error Model:** Custom algorithm to evaluate detection accuracy (TP/FP/FN) using simulated ground truth.
6. **Wireless Data Generation:** Beamforming module using Wireless Insite for propagation modeling.

**Signal Flow:**
Geographic Map -> Traffic Simulation (SUMO) -> 3D Environment (Blender) -> LiDAR Point Cloud -> Detection Algorithm -> Performance Evaluation (Error Model) -> Antenna Beam Steering (Beamforming).

Image: _page_2_Figure_9.jpeg
Type: Flowchart (Fig. 3: Transition algorithm logic)
---
**Process Flow:**
- **Initialization:** Reads physics data (ID, coordinates, angle, speed), creates 3D ground plane with a specific "Plane radius."
- **Timestep Loop:** Iterates through discrete time segments generated by SUMO.
- **Vehicle Loop:** For each vehicle ID:
  - Extracts attributes (Lat/Long, Angle) from XML files.
  - Converts geographic coordinates to 3D local coordinates.
  - **Spatial Filtering:** Checks if coordinates are "inside the plane" (LiDAR coverage).
  - **Memory Management:** If the Veh_ID is new, it imports a 3D car object; otherwise, it extracts the relevant object from the active list.
- **Keyframing:** Imposes the precise (x, y, z) location and yaw angle into the Blender timeline.

**Axes Extraction:**
- **X-axis:** Distance from the LiDAR (m) [10 to 80].

**Data Points & Trends:**
- **Mean Error (Red circles + Bars):** 
  - Starts high at the sensing limit (15m) near 0.9m.
  - Drops to a minimum of **~0.1m** at 20-30m distance.
  - Gradually increases linearly to **1.1m** at 70m.
- **False Negatives (FN - Blue dashed):** Sharp, exponential spike starting at 70m, reaching a zenith of **~330-340 counts** at 75m (LiDAR range threshold).
- **False Positives (FP - Magenta dashed):** Remains low (< 50 counts) with minor fluctuations near 40m and 65m.
