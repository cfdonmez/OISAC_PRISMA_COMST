## Image: _page_3_Picture_1.jpeg
### Type: System Diagram (ISAC Channel Model)

### Channel Components:
- H_ISAC = H_background + H_target
- H_background: Multipath not impacted by target (clutter)
- H_target: Divided into TX-Target and Target-RX paths

### Path Types:
- LOS direct path (TX/RX to target)
- NLOS paths (via environment clutter)

### Key Equation:
L_TX-SPST-RX = PL(d1) + PL(d2) + 10log(c²/4πf²) - 10log(σ_RCS) + SF

### O-ISAC Relevance:
- Foundation for 3GPP Rel-19 ISAC channel modeling
- Extends TR 38.901 for sensing targets

## Image: _page_7_Figure_1.jpeg
### Type: Block Diagram (Nokia ISAC PoC Architecture)

### System Components:
1. **Comms RU (TX)**: Transmits OFDM sensing signal
2. **Sniffer RU (RX)**: Receive-only unit for sensing
3. **Synchronization**: eCPRI fronthaul, PTP/SyncE (jitter ≈40 ps)
4. **SPU**: Sensing Processing Unit (GPU server)
5. **DU/L1 High**: Distributed Unit for coordination

### Processing Pipeline:
1. Pre-generated OFDM frames → TX RU
2. Reflected signal acquisition → Sniffer RU
3. CTF estimation (equalization)
4. Clutter removal algorithms
5. OFDM radar processing (FFT)
6. Range-Doppler periodogram
7. Target detection + AI/ML classification
8. Kalman filter tracking

### Key Specifications:
- Frequency: ~27 GHz (mmWave)
- Bandwidth: up to 400 MHz
- TDD: DL:UL = 4:1
- Subcarrier spacing: 120 kHz
- Range resolution: 0.39 m
- Speed resolution: 0.55 m/s
- Processing latency: <10 ms
- Beam configuration: up to 128 beams

### O-ISAC Relevance:
- Commercial 5G hardware demonstration
- Quasi-monostatic (separate TX/RX to avoid full-duplex)
