Type: System Diagram / Schematic (Space-Division Multiplexed ISAC Architecture)
---
Components:
- ECL: External Cavity Laser at 1550 nm.
- PBS: Polarization Beam Splitter.
- IQ Modulator ×2: Dual-polarization modulation.
- AWG: Waveform generator (10 GSa/s).
- EDFA ×2: Polarization diversity amplification.
- MCF (Multi-Core Fiber): 7-core fiber, 50 km.
- Fan-in/Fan-out: MCF-SMF interface.
- Circulator Array: 7-channel Tx/Rx routing.
- Collimator Array: 7-beam spatial diversity.
- Target Scene: Multi-target environment.
- PD Array: 7-element coherent receivers.
- LO Distribution: Shared local oscillator.
- Real-time DSP: GPU-based processing.

Flow:
1. ECL → PBS → IQ Mod (Pol X, Pol Y) → EDFA.
2. Fan-in → MCF (7 cores, 50 km) → Fan-out.
3. Circulator Array routes to Collimator Array.
4. 7 beams illuminate Target Scene.
5. Return signals → Circulators → PD Array → DSP.
---
