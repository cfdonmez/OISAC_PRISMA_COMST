# O-ISAC COMST Overleaf Core Package

This archive contains only the files required to compile the manuscript.

## Overleaf settings

- Main document: `main.tex`
- Compiler: pdfLaTeX
- TeX Live: latest available version
- Bibliography: BibTeX, handled automatically by Overleaf

Upload the ZIP as a new Overleaf project and compile `main.tex`. The archive
intentionally excludes generated auxiliary files, the locally compiled PDF,
editable figure sources, QA previews, supplements, and project history.
