# Reconstructed Freeze Bundle - 2025-11-30

Purpose:

- This folder is the best reviewer-readable substitute currently available for the missing original freeze-time raw export pack.
- It consolidates the canonical aggregate search log, the source-level reconstruction files, the freeze provenance notes, and the visible later update exports in one place.

Important boundary:

- This is a **reconstructed freeze bundle**, not the original `2025-11-30` raw export pack.
- The visible IEEE and Scopus CSV exports in this folder are dated `2025-12-28` and should be interpreted as later update-wave exports.
- No matching freeze-time Web of Science export is currently present in the repository snapshot.

How to use this bundle:

- Use `search_log.csv` for the canonical aggregate database split (`410 + 320 + 250 = 980`).
- Use `formal_identification_reconstruction_20251130.csv` to show which parts are directly visible versus reconstructed.
- Use the provenance notes when a reviewer asks why `2025-11-30` remains the declared freeze date.
- Do not describe this folder as a row-level freeze-time raw-search archive.
