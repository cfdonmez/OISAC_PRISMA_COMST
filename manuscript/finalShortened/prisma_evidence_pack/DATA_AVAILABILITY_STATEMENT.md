# Data Availability Statement Options

## Option A: Public repository plus supplement

`The PRISMA 2020 audit package supporting the study-selection flow is available in the supplementary materials and in an open repository. The package includes the protocol, search-strategy documentation, PRISMA flow counts, the reconciled full-text exclusion log, the full-text assessed reconstruction, and the final included-study ledger. Because some source-platform exports may be subject to database-specific redistribution restrictions, the public package provides derived audit files rather than redistributing proprietary raw-search exports.`

## Option B: Public repository only

`Derived materials supporting the PRISMA 2020 study-selection flow are archived in an open repository, including the protocol, search strings, flow counts, full-text exclusion records, and included-study ledger. Raw database exports are not redistributed in the public archive where platform-specific access restrictions may apply; instead, the archive provides derived audit files sufficient to inspect the reported study-selection trail.`

## Option C: If some files must remain non-public during review

`A reviewer-readable PRISMA audit package has been prepared and can be provided upon request during peer review. The public archive will include the protocol, search-strategy documentation, PRISMA flow counts, full-text exclusion log, and included-study ledger after acceptance. Raw source-platform exports are not redistributed where database-specific access restrictions apply.`
