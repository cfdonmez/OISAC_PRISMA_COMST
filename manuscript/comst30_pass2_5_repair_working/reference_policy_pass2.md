# Reference Policy for Pass 2

## Principle

The complete 220-study included-corpus bibliography remains in `references.bib` and should remain traceable through the screening ledger, extraction sheet, supplementary evidence records, and public repository / Zenodo package. The main COMST manuscript should cite representative and load-bearing studies rather than forcing all 220 records into the printed reference list.

## Changes Required in Pass 2

- Remove `\nocite{*}` from the working manuscript.
- Keep all 220 bibliography entries in `references.bib`.
- Compile only references that are actually cited in the main text.
- Retain the full corpus externally through the corpus ledger and supplementary package.

## Citation Architecture

- Table I rows should cite the relevant survey or modality anchors.
- Each modality paragraph should cite several representative records.
- Each enabler family should cite representative records.
- Section V should cite key records and/or corpus-ledger support while keeping the numerical governed-subset result unchanged.
- Applications should cite representative examples for each macro-domain.
- Roadmap claims should cite review, standards, or benchmark-context records where appropriate.

## Deferred Reference Slimming

Audit-tail and component-only records should stay in the corpus ledger unless they are needed for a main-text claim. They should not be cited merely to preserve visibility in the printed reference list. This preserves systematic-review traceability while avoiding a 220-item main bibliography.
